# Soleil

Hack'n Slash 2D top-down en pixel art, multijoueur en ligne mondial, jouable dans le navigateur.

Le projet est en phase de conception. Le dossier complet (game design, architecture technique,
réseau, serveur, client, base de données, sécurité, monitoring, tests de charge, roadmap) se
trouve dans [`docs/`](docs/README.md).

Outils :

- `python3 tools/balance/xp_curve.py` — génère la courbe d'XP et les taux de drop des Soleils.
